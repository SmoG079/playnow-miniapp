# PlayNow 界面规范

2026-11-05，全站 36 个路由。以当前 uni-app / Wot UI 2.3.2 实现为准。

## 方向：球场边的俱乐部

服务找球友、组织比赛和管理俱乐部的人。以真实活动名称、时间、场地、报名状态为视觉主体。保留球场绿，白色内容区与浅灰底区分层级；不使用装饰渐变、漂浮阴影、英语眉题、重复标签和巨型空状态。图片只在活动、俱乐部等内容中出现。

- 球场绿 `#147553`：主操作、选中、可报名。
- 深绿 `#183F30`：品牌、账户重点信息。
- 墨色 `#20342B`：正文与标题。
- 次要文字 `#617268`：地点、说明、时间等，保持可读对比度。
- 页面底 `#F5F7F6`、内容白 `#FFFFFF`；分隔线 `#E1E7E3`。
- 警告、错误仍保留独立语义色，不将全部状态染绿。

字体采用设备中文黑体（PingFang SC / Microsoft YaHei），拉丁文字使用系统 sans-serif；不加载网络字体。页标题 26px、二级导航 18px、区块 18px、正文 15px、辅助 13px，最低 12px。金额和比分使用等宽数字。常规/中等/粗体分工，避免到处粗体。

## 页面结构

左对齐，20px 页面边距（窄屏 16px），4/8px 间距体系。圆角按对象分工：字段 10px、卡片 14px、弹层 20px、头像圆形。主列表由内容分隔，设置项合并为一个列表，避免每一行一张卡。交互控件最小高度 44px；小屏按钮允许换行，底部操作区留安全区且不遮挡内容。

```text
发现 / 俱乐部           详情 / 管理             创建
城市       微信胶囊     返回  标题  微信胶囊    返回  标题
主标题 + 地区天气       图片 / 名称             封面（选填）
筛选（低强调）          时间、地点、状态        基本信息
活动 / 俱乐部内容       报名 / 成员 / 记录      报名设置
原生五栏导航            底部主操作 + 安全区     次要配置 + 保存
```

初始引擎输出为通用预约漏斗、蓝橙色及西文展示字体，不适合中文网球社群，未直接采用；二次 product 查询命中 Sports Team/Club，采用其品牌一致性建议。Vue forms 查询涉及 3.5，本项目为 3.4，保留现有 Wot 表单和校验，不引入额外库。Wot API / token 通过项目 MCP 的 2.3.2 数据核对，并以已安装样式确认生效变量。

## 实现与验收

ConfigProvider 在自身根节点显式映射品牌语义变量，避免组件库浅色主题重设为蓝色。公共 token 在 `frontend/src/styles/tokens.scss`，布局在 `theme.scss`，创建表单在 `creation-form.scss`。页面特例使用 token，不堆叠全局覆盖。保留原生 tabBar、首页第一路由、现有鉴权及业务数据流。旧订场关闭页面明确展示现状，两个历史活动入口仍重定向。

验收覆盖所有路由的继承关系、主要页面的有内容/空/失败状态、窄屏长标题、筛选弹层、长表单、固定底栏。模拟数据仅在临时验收工具内；不写入生产。构建与模拟器验证结果记录在本轮报告，不沿用历史通过记录。
