# 活动草稿与问卷定级（2026-10-09）

## 已实现的活动草稿

- 比赛与约球表单提供“保存草稿”，编辑时及退出页面时也自动保存。
- 草稿保存在当前设备，按 AppID/API 环境、账号、活动类型和编辑目标隔离；不因退出或超过 24 小时自动失效。
- 恢复表单、已上传封面、活动位置、俱乐部选择、预约关联；比赛还恢复规则配置和展开面板。
- 发布或保存赛事成功后仅删除对应草稿；失败时保留。
- 原比赛缓存按原有效期读取，读取成功后迁入新的持久草稿结构。
- 本地草稿不跨设备同步；已有预约不会因保存草稿延长有效期，实际发布仍由后端验证预约及权限。

## 已实现的 NTRP 自评

- 个人资料 NTRP 栏旁提供绿色“测测我的等级”，点击打开底部弹窗，支持关闭、滚动与安全区。
- 快速选档按用户截图提供 1.5 初识、2.5 入门、3.5 会打、4.5 熟练；选择后显式确认并保存。
- 完整问卷包含底线相持、反手、发球、接发、网前和实战六题，需全部回答；可返回修改。
- 服务端统一校验模式、版本、完整答案及选项范围，不接受客户端评分或 UTR 值。
- 问卷完成后立即写入当前用户的 `ntrp_level`，保留问卷答案、版本与时间，并同步资料选择框和会话标签，无需再次点击资料保存。
- 保存失败保留弹窗及答案，可重试；未选择或未完成时禁用提交。

用户已明确不要求复现 UTR 官方计分，并进一步要求问卷不计算或保存 UTR，仅预留字段。当前题目为 PlayNow 原创中文能力描述，参考常见自评维度与截图布局：
https://t-ennis.tw/tools/ntrp-utr/
https://www.tennisss.com/ntrp/quiz

规则版本 `playnow_self_v2`：每题八档对应 NTRP 2.0 至 5.5；完整问卷取六项能力等级的等权平均值，按 half-up 四舍五入到 0.5 档。快速选档直接使用所选 NTRP 等级。该算法是项目自评规则，不是转载问卷的官方算法，不保证评级精度。弹窗明确标注仅供参考、可重新测评；未添加“前五场比赛自动校准”等未实现承诺。

新增 nullable 字段：`users.utr_rating` 为预留字段，现阶段默认空，不通过问卷赋值或展示；`rating_assessment` / `rating_assessed_at` 保存 NTRP 定级答案/算法版本与时间。手动改变 NTRP 会清除对应问卷来源，保留当前或未来的 UTR 值；同等级资料保存保留问卷来源。资料和问卷响应均不暴露 UTR。

迁移版本：`20261009_user_rating`，基于 `20261009_review_integrity`。隔离验证及正式库恢复副本演练通过后，已随本次后端发布执行正式迁移。
