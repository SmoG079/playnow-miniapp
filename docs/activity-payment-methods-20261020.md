# 约球和比赛的付款方式（2026-10-20）

收费活动发布页新增「线下付款／线上付款」，新建页面默认线下付款，金额为 0 时按免费活动处理。付款方式随草稿保存；比赛编辑恢复原付款方式。有报名记录后不能修改费用或付款方式，避免报名后变更收款约定。

报名弹窗展示每人金额。线下方式明确提示「报名时无需线上支付，报名成功后由组织者自行组织收款」；没有审核、候补等限制时直接报名成功。原有审核、容量、截止时间、固定搭档和候补规则仍适用。线下报名不创建微信订单、不记录为线上已付款，也不调用线上退款；线下退费由参与者与组织者协商。比赛的线下已确认报名可正常组队和抽签，候补递补后无需支付。

比赛线上报名沿用现有微信支付及取消退款规则。新增约球线上报名订单，只有经过真实收款校验后才进入已通过或待审核状态；支付前保留名额，超时释放。支付关闭、重复通知、取消、拒绝审核、组织者关闭活动、报名失效后的迟到收款均按本订单状态处理，需退款时持久化退款意图并复用原退款单。约球自助取消沿用原有取消入口，线上已付款全额退款。退款与报名取消不恢复资格。

新支付统一遵循 `WX_PAY_ENABLED`；关闭时免费和线下报名正常。约球支付状态查询与支付入口按登录用户校验，复用支付频率限制；场地预约接口拒绝处理约球订单。约球订单通过既有统一回调分发，定时任务兜底查单和关单，退款由既有持久化退款任务处理，不生成场地分账或变更场地时段。

## 迁移与上线

新增 Alembic `20261020_activity_payment`，前置为 `20261019_tournament_owner`。历史约球回填线下，历史比赛保留线上；已有约球的费用仅代表线下收款约定，不伪造线上订单。新增约球订单关联、报名付款状态及名额过期时间，保留外键。上线需先按正式部署流程执行迁移，再更新后端及小程序。
