# 约球帖详情页规范 (SSD)

## 参考设计
基于网球活动报名平台的详情页设计，包含场馆图片、活动信息、报名状态、参与者列表和底部操作栏。

## 页面结构

### 1. 顶部图片区
- 全宽图片，高度 400rpx
- 图片下方渐变遮罩（底部 30% 区域，黑色渐变到透明）
- 左上角返回按钮（白色箭头）
- 右上角更多选项（白色三点图标）

### 2. 活动标题区
- 如果有认证标识（如 UTR），显示蓝色徽章
- 标题：大字加粗，黑色
- 标签行：灰色小字，用 | 分隔，如：
  - `有顶棚 | 满4人开赛 | 冠军400 | 电子裁判`

### 3. 信息列表
| 标签 | 内容 | 备注 |
|------|------|------|
| 发起人 | 用户昵称 + 电话图标 | 点击可拨打电话 |
| 时间 | 日期 星期 开始时间 - 结束时间 | 如：06月10日 周三 09:30 - 13:30 |
| 地点 | 场馆名称 + 详细地址 | 右侧有导航箭头 |

### 4. 价格 & 报名状态
- 左侧：价格（橙色大字）
- 右侧：报名状态（绿色）+ 右箭头
  - 格式：`已报名 {current}/{max}`
  - 示例：`已报名 8/16`

### 5. 已报名用户
- 标题："已报名用户" 或隐藏
- 头像列表：横向排列，圆形头像
- 每个头像下方显示昵称
- 超出显示数量时，最后一个显示 `...`
- 点击头像可查看用户资料

### 6. 底部固定操作栏
- 左侧：群聊按钮（图标 + 文字）
- 中间：分享按钮（图标 + 文字）
- 右侧：主操作按钮（绿色大按钮）
  - 未报名："报名 ¥{price}"
  - 已报名："已报名"
  - 已满员："已满员"
  - 已截止："已截止"

## 交互逻辑

1. **页面加载**：调用 GET /api/v1/posts/{id} 获取详情
2. **报名按钮**：
   - 未登录 → 跳转登录页
   - 已报名 → 显示"已报名"，点击可取消
   - 未报名且未满员 → 调用 POST /api/v1/posts/{id}/register
   - 已满员 → 按钮置灰
3. **发起人电话**：点击拨打电话（需后端返回 phone 字段）
4. **地点导航**：点击打开地图导航
5. **分享**：调用微信小程序分享接口
