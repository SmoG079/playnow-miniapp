# 约球帖发布功能实现记录

## 已完成的修改

### 后端

**文件：** `backend/app/api/v1/posts.py`

1. 导入 `ClubMember` 模型
2. 在 `create_post` 函数开头增加权限校验：
   - 查询 `ClubMember` 表，检查当前用户是否为指定俱乐部的成员
   - 如果不是，返回 HTTP 403，错误信息："只有俱乐部管理员才能发布约球帖"

### 前端

**文件：** `miniprogram/pages/publish/post-create.js`

1. `loadClubs()` 函数修改：
   - 先检查 `app.globalData.managedClubIds`，如果为空数组，提示无权限并返回
   - 加载俱乐部列表后，只保留用户管理的俱乐部（`filter`）
   - 如果过滤后为空，同样提示无权限并返回

**文件：** `miniprogram/custom-tab-bar/index.js`

1. 发布入口的 `show` 从 `true` 改为 `hasClub`
2. 无俱乐部用户点击「+」按钮后，看不到「发布约球帖」选项
