# 活动地点与底栏同步（2026-10-15）

底栏每个页面都有独立实例。旧逻辑延后读取全局页面栈，并在切换成功后同步离开页面的实例；目标页可能仍读到旧路由。新逻辑在点击时即时选中，目标页面按自身身份同步自己的底栏，切换失败才回滚；过期回调不覆盖后续点击。不以旧图标的选中值判断是否已经进入目标路由。

约球、比赛使用相同的时间地点展示组件：时间含月日、星期和时分；地点名称置于上方，详细街道地址置于下方，可点击导航。地图选点返回的 name 保存到 location_name，address 只存详细地址；关联场地由服务端提供名称。

迁移 20261015_location_names 为两类活动添加独立的 location_name 字段，并一次性回填关联场地的名称。此前只存地址的自由活动无法推断真实地点名，不从街道地址猜测名称，不增加旧字段或旧接口兼容分支。

验证覆盖延迟路由栈、目标底栏实例、快速切换后旧失败回调、过期绿色选中态，以及两类活动地点名称与地址的独立保存。隔离 MySQL 完成空库升级、重复升级及正式库只读副本升级；副本升级前后所有原列的行数及内容哈希保持一致。
