## 已发现并修复

1. 登录后查询消息未读数量被数字消息详情路由匹配，返回 422；数字 ID 路由增加整数匹配约束。
2. 分账列表被数字订单详情路由匹配，返回 422；修复后仍仅允许平台管理员，普通用户和俱乐部管理员返回 403。
3. 场地排期按日期范围查询时，参数 `date` 遮蔽日期类型，导致 500；使用独立日期类型名称。
4. 时段未设置覆盖价时返回 0，而非场地每小时基础价；保留覆盖价优先。
5. 有回复评论的帖子删除时违反评论自引用外键；先删除回复，再删除根评论。
6. 未提交 Authorization 时返回 422，改为 401，以支持前端登录恢复。
7. 正式环境允许 `dev_` 代码绕过微信登录，现仅 DEBUG 环境允许。正式微信 code 登录路径保留。
