# 定场约球发布权限调整

2026-10-07：自由约球、定场约球均向所有登录用户开放，比赛发布仍按主办俱乐部管理权限校验。此规则取代早期文档中定场约球只允许管理员发布的要求。

- 发布约球页允许所有登录用户选择俱乐部并完成订场；订场回传包含俱乐部 ID，返回发布页时恢复选中项。
- 定场约球接口校验预约属于发布者、业务类型为场地预约、状态为 `paid`，且预约、场地、俱乐部一致。缺少预约、其他人的预约、未支付或已取消等预约不能关联。修改关联信息时执行同样校验。
- 未关联场地则发布自由约球。取消关联不会取消原场地预约。兼容旧管理员仅关联俱乐部的发布路径，仍保留原有权限校验。
- 页面点击查看的对比表中，两种约球的发布者均显示“所有登录用户”。

本次不接入真实场地预订支付或退款；`paid` 遵循现有预约状态约定，不等同真实收款已验收。本次代码未部署。
