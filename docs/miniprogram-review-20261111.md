- 主办方能拿到已报名选手的手机号，是为了赛事当天的现场联络（迟到、场地变更、签到），属业务必需；

## 四、审核路径（怎么走到这些页面）

### 路径 A：约球活动退款（推荐，最短）

1. 用**选手账号**登录 → 首页 → 约球/活动列表 → 打开一个付费约球活动 → 报名并支付（金额较小，¥30 左右）
2. 用**组织者账号**登录（该活动的发起人）→ 进入同一活动详情 → 点击「报名审核」→ 找到刚报名的选手
3. 点击「全额退款」→ 二次确认 → 提示「已退款」，按钮变为灰色「已退款」

### 路径 B：赛事报名退款

1. 用**选手账号**报名一个付费赛事并支付
2. 用**组织者账号**打开该赛事详情 → 报名列表中点击「全额退款」
3. 成功：按钮变灰「已退款」；失败：弹窗显示失败原因

> 若审核期间不想产生真实资金流水，可只验证路径 A 的**界面状态**（按钮文案、置灰状态、弹窗样式），无需完成支付步骤。

### 路径 C：联系方式与俱乐部（无需支付）

1. 任意打开一个赛事或约球详情 → 滑到页面底部 → 「组织者」卡片上点**电话图标**（调起拨号盘）或**消息图标**（进入站内会话）
2. 用组织者账号打开同一活动 → 「报名管理 / 报名审核」→ 每条报名右侧的**电话 / 消息**
3. 若活动关联俱乐部：详情页「俱乐部」卡片右侧点**「加入」**→ 按钮变为「已加入」；点卡片进入俱乐部详情

### 路径 D：NTRP 水平自评（无需支付）

1. **我的** → **编辑资料** → **NTRP 水平评估**
2. 选「快速评估」直接选等级，或「完整问卷」逐题作答
3. 提交后返回个人资料，NTRP 等级即为刚选的/计算出的值。全程不产生上传作答明细的请求

## 七、可能被驳回的点与应对

1. **「涉及虚拟支付，需接入小程序虚拟支付」**
   → 说明业务为线下场地预约（可提供场馆照片、营业执照经营范围含体育场馆经营），并按官方《虚拟支付业务运营指南》第 4 节申请与实际经营相符类目（生活服务 > 运动健身），限制会自动解除。
2. **「缺少测试账号 / 无法验证功能」**
   → 补填第五节表格，并在备注里写清"需要组织者账号才能看到退款按钮"。
3. **「页面无数据」**
   → 确保测试账号下有正在进行（未结束）的付费活动 + 付费赛事，且报名名额未满。
4. **「退款按钮点了没反应」**
   → 说明是商户余额不足导致退款被拒，页面会有弹窗提示；审核验证时请先确认余额充足，或只验证按钮状态与文案。
