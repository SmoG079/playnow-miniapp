# 全站界面优化与验收（2026-11-05）

本轮使用 frontend-design、ui-ux-pro-max、项目 wot-ui-v2 Skill，并通过 Wot MCP 查询 2.3.2 的 ConfigProvider、Button、Input、Textarea、InputNumber、Cell、Search、Tag、Popup、Empty、Tab、Icon。微信开发者工具验收使用 wechatide-skill 的 compiler / automator / debugger 流程。

## 设计与实现

统一方向为“球场边的俱乐部”，详细规范见 [设计基准](../design-system/playnow/MASTER.md)。保留网球场绿、真实活动图片和原生五栏导航，以活动时间、地点、报名状态为主要信息。

- 新增 `styles/tokens.scss`：页面、文字、品牌、描边、圆角、触控高度与 Wot 公共变量。通过 AppShell 的 ConfigProvider 显式设置语义色，修复其默认浅色主题覆盖页面主色，导致绿色按钮与蓝色描边/标签页并存的问题。原生按钮的全局 reset 排除 Wot 按钮，避免抹去小程序中由伪元素绘制的 plain 按钮边框。
- 首页减少重复标题和装饰，筛选移除渐变与阴影。活动卡片减少重复文案，提高时间、地点及费用可读性；长标题和地址可换行。
- 发布页突出发布约球，比赛与俱乐部入口使用安静的列表层级。个人菜单合并为连续列表；活动提现图标替换为安装包内存在的图标。
- 俱乐部列表增加明确的加载、失败重试状态，避免把接口错误当作空列表。俱乐部详情整理封面、身份、介绍及成员管理布局。
- 约球/赛事详情统一信息块和文字颜色，赛事标签分隔，窄屏标签页不再截断“参与者”，底部操作支持换行并预留滚动安全空间。
- 创建表单统一字段、留白与章节；封面占位压缩；计数器与帮助按钮扩大触控区；时段管理补充日期、时间、间隔标签；俱乐部和场地表单使用具体占位说明。
- 消息列表改为连续会话行；私信长内容可换行，H5 缺少原生键盘高度 API 时使用能力判断，避免页面生命周期报错。
- 提现页日期筛选改为稳定网格，金额、长流水与按钮可换行；UTR 页面保留成绩层级，颜色回归品牌并去掉重复英语装饰标签。
- 三个暂停订场入口复用 BookingUnavailable，明确现状并提供俱乐部、历史预约入口。保留两个旧活动路由的重定向。
- 所有普通页面继承公共导航、菜单、记录卡片、表单及安全区布局；管理页同步受益。首页仍为第一路由，UTR 页的原生导航背景与其深绿页头对齐。

未修改后端、API 地址、支付/退款/鉴权规则；未接入新字体或图片资源；未上传体验版或发布。

## 隔离与限制

截图中的活动、姓名、金额、消息均为临时验收数据。H5 浏览器拦截全部非本地请求；微信模拟器 mock request 及存储读取/写入/删除，避免使用真实业务接口或改动原登录与草稿数据。验收后先退出表单，再恢复 mock 并刷新模拟器。

本轮没有真实支付、提现、报名、审核、消息发送或场地生成。未做真机验收、微信系统最大字号、屏幕阅读器和完整深色模式验证；H5 放大字号仅为布局压力测试，不能代替真机字号测试。复杂比赛签表的全部人数、赛制与历史数据组合未穷举。
