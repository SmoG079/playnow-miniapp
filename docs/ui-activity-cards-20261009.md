# 登录页与活动卡片视觉调整（2026-10-09）

承接用户对 GameConnect 页头参考的补充反馈：登录页简化，比赛与约球卡片增加活力。沿用 PlayNow 绿色、原生五入口及现有详情和管理操作。

## 登录页

顶部仅显示返回与“登录”，取消地区、天气以及重复的品牌与口号。`AppShell` 可通过 `simple-header` 使用简洁页头；这种页头不触发天气查询。保留微信登录、协议选择和登录回跳逻辑，登录按钮适配底部安全区。

## 活动卡片

新增共享 `ActivityCard.vue`，首页和“我的活动”复用：

- 比赛：封面图、底部渐暗遮罩、开赛日期与大号时间；浅绿色类型标签、报名状态、主标题、地点或主办俱乐部；已报名人数、细进度条与查看入口。
- 约球：绿色日期块、星期和起止时间；有上传图片时显示缩略图，无图片时显示 CSS 绘制的小网球场；球友头像、发起人、NTRP 信息与报名人数分层展示。
- 长标题允许自然换行；地点和元信息保持较弱颜色，绿色与嫩绿强调日期、人数和查看入口。
- “我的活动”保留报名结果、报名处理、编辑、关闭、个人分组与对阵的独立操作。个人记录接口缺少报名人数时不显示虚构人数；缺少场地关联字段时使用“约球活动”，不推断为自由约球。
- 比赛时间按当前服务端 UTC-naive 约定转为上海时间，明确跨日结束日期；约球日期、时间仍按业务当地时间展示。满员进度封顶，已关闭和已结束状态优先于人数。

图片复用 `Photo.vue` 和现有本地网球照片，未引入额外图片资源或修改业务接口。Wot Tag、Icon 用法已查询匹配 2.3.2 的项目 MCP。

## 验证

- 类型检查通过；22 个测试文件、91 项前端测试通过。新增 5 项日期时区、跨日、缺失人数、进度边界及状态优先级测试。
- Wot lint 无错误，9 条原有子组件识别警告；小程序生产构建通过。
- 开发者工具检查首页两类卡片、登录页、我的活动中比赛与约球、我发布的约球操作，以及长标题、长地点、满员、缺封面、跨日比赛。
- 比赛和约球卡片点击均进入对应详情；个人对阵展开正常；我发布的约球保留“处理报名”和“关闭约球”。未实际报名、支付、关闭活动或提交表单。
- 登录页地区选择器数量为 0；清空临时请求记录后进入登录页，没有天气或其他接口请求。
- 检查使用临时接口与存储 mock；样例不进入产品源码，验收后恢复并刷新。运行时确认 `fixturePresent=false`、`mockToken=false`，当前为真实首页；刷新后 console 的 error 查询无匹配记录。当前天气真实服务的部署限制仍见上一轮记录。
