# PlayNow 首页设计分析（参考截图）

## 目标
将当前首页从「约球广场」升级为「比赛/活动聚合页」，参考截图中的卡片式信息流设计。

---

## 一、顶部导航结构

### 当前实现
- 搜索栏（🔍 搜索俱乐部、比赛、约球...）
- 运动类型筛选（全部/羽毛球/篮球/网球/乒乓球/足球）
- 排序切换（最新发布/距离最近）

### 参考设计
- **城市定位**：📍 杭州 ▼（左侧，可切换城市）
- **功能按钮**：翻译、更多菜单、扫描（右侧）
- **运动类型 Tab**：🎾 网球比赛（选中）| 🏓 匹克球比赛（未选中）

### 需要修改
1. 移除搜索栏（或缩小为图标）
2. 添加城市定位（先写死为当前城市，后续接地图 API）
3. 运动类型改为 Tab 切换（只保留网球）
4. 筛选改为：时间 | 排序 | 评级 | 筛选

---

## 二、筛选排序区域

### 参考设计
四个灰色圆角胶囊按钮：
| 按钮 | 功能 |
|------|------|
| 时间 ▼ | 日期范围选择 |
| 排序 ▼ | 距离/时间/热度 |
| 评级 ▼ | NTRP/UTR 等级筛选 |
| 筛选 ▼ | 综合高级筛选 |

### 需要实现
1. 时间筛选：今天/明天/本周/自定义
2. 排序：距离最近/时间最近/热度最高
3. 评级：NTRP 等级多选（2.0/2.5/3.0...）
4. 筛选：价格范围、场地类型、人数

## 三、比赛卡片（核心）

### 卡片结构（从上到下）

```
┌─────────────────────────────────────┐
│ [组织者Logo] 青乐网球俱乐部            │
│ 青乐网球积分赛NTRP3.0单打 [✓认证]    │
│ ┌──────────┐                        │
│ │  图片     │  ⏱ 06.11 周四 11:00   │
│ │  区域     │  📍 青乐网球俱乐部      │
│ │  (左)     │  🧭 13.0km             │
│ └──────────┘                        │
│ 👤👤👤👤 已报名: 4/4    [去报名]     │
└─────────────────────────────────────┘
```

### 元素拆解

| 元素 | 说明 | 数据来源 |
|------|------|---------|
| 组织者 Logo | 左侧小图标 | `post.club_cover_image` |
| 组织者名称 | 灰色文字 | `post.club_name` |
| 标题 | 黑色粗体 | `post.title` |
| 认证徽章 | 绿色/蓝色 ✓ | `club.is_verified` |
| 图片 | 左侧方形，场馆/比赛图 | `post.cover_image` 或 `club.images[0]` |
| 时间 | ⏱ MM.DD 周X HH:MM | `post.preferred_date` + `preferred_start` |
| 地点 | 📍 场馆名称 | `post.venue_address` |
| 距离 | 🧭 X.Xkm | 后端 Haversine 计算 |
| 报名人数 | 头像堆叠 + 已报名: X/Y | `post.registration_count` + `players_needed` |
| 报名按钮 | 绿色圆角按钮 | 根据是否已满/已报名显示不同状态 |

### 报名按钮状态
| 状态 | 显示 | 操作 |
|------|------|------|
| 可报名 | 绿色「去报名」| 跳转详情页 |
| 已满员 | 灰色「已满员」| 不可点击 |
| 已报名 | 绿色「已报名」| 跳转详情页 |
| 已结束 | 灰色「已结束」| 不可点击 |

## 五、颜色方案

### 主色调
| 颜色 | 色值 | 用途 |
|------|------|------|
| 薄荷绿 | `#5CD29D` | 主品牌色、选中态、按钮 |
| 深绿 | `#4CAF50` | 按钮按下态 |
| 白色 | `#FFFFFF` | 卡片背景 |
| 浅灰背景 | `#F5F5F5` | 页面背景 |

### 文字层级
| 层级 | 颜色 | 用途 |
|------|------|------|
| 标题 | `#333333` | 比赛标题 |
| 正文 | `#666666` | 地点、组织者 |
| 辅助 | `#999999` | 时间、距离 |

### 认证徽章
| 类型 | 颜色 | 含义 |
|------|------|------|
| 绿色 ✓ | `#4CAF50` | 官方认证/高级俱乐部 |
| 蓝色 ✓ | `#2196F3` | 普通认证 |
