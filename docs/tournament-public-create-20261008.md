# 比赛发布权限开放（2026-10-08）

所有登录用户可以创建及预览比赛，主办俱乐部仍须存在，赛制、地点、时间及人数校验保持。发布页开放入口和全部俱乐部选择，去除俱乐部管理员发布限制。

以服务端创建审计确认创建者：创建者可以编辑、管理报名、抽签发布、排场、录分和关闭自己的比赛，管理列表及详情同步返回权限。平台管理员和原有具体俱乐部管理员权限保持；其他普通用户不能操作他人的比赛。没有创建记录的历史赛事沿用原俱乐部权限，不推断创建者。

验证覆盖普通用户创建、预览、管理列表、编辑、抽签发布、录分和关闭，以及其他用户越权拒绝和不存在俱乐部拒绝。小程序类型检查、32 项测试、生产构建和上传 dry-run 通过；Wot lint 无错误，保留既有子组件元数据警告。无需数据迁移。
