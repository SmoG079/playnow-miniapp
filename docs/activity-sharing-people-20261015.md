# 活动分享与约球人数（2026-10-15）

约球、比赛详情页接入好友/群聊分享和朋友圈分享，分享标题、详情 ID 和封面随活动生成。页面提供好友/群聊按钮，朋友圈按钮引导使用微信右上角菜单。朋友圈只分享当前详情的 ID；普通比赛分享不含搭档邀请，只有“分享搭档邀请”按钮携带邀请参数。分享需由用户主动发起。

朋友圈 scene=1154 按匿名预览处理，不读取登录凭证、不刷新令牌、不启动消息轮询。活动详情可公开查看，报名、评论、联系发起人等登录操作引导点击微信的“前往小程序”。进入完整小程序后仍需登录，后端两个报名接口保留强制鉴权。

约球最低/最大人数按总人数计算，包含发起人，前端设置范围 2–31。最低人数为成团目标，不触发自动取消或退款；最大人数用于限制名额。审批中的报名不计入已确认人数。数据库仅使用 min_players/max_players 保存总人数；发起人不得再次报名。列表与详情显示包含发起人的人数。

新增迁移 `20261015_post_people`，为 match_posts 增加非空 min_players/max_players。旧最低人数设为 2，最大人数由原 players_needed + 1 转换，不小于已确认人数加发起人；发起人的历史自报名标为取消并保留记录，重新计算开放/满员状态，然后删除旧 players_needed 字段。API 与前端只使用新人数模型，不保留旧字段兼容。拒绝最低大于最大的人数设置，缩减最大人数不能低于已确认人数加发起人。
