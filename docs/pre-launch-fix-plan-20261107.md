- 本批交付为合规代码修改、构建和体验包上传。生产部署、运营后台配置、微信提审和正式发布分别验收。
- 公网入口为 `https://www.tennisplaynow.site`。443 为当前入口，8443 保留历史兼容。

## 1. 隐私授权和指引

### 小程序改动

- 删除登录页无法查看正文的协议复选框和相关门禁。微信端在用户点击登录后调用 `wx.requirePrivacyAuthorize`，成功后才执行 `uni.login` 和服务端登录。拒绝时保留登录页并允许重试，基础库缺少该接口时提示升级微信。
- 首页冷启动也可能在登录前尝试定位，已有定位失败提示和手动选城入口。位置权限、隐私授权和登录需分别验证，避免把首页定位当作登录告知。定位声明继续保留 `getLocation` 和 `chooseLocation`。
- 开启开发工具域名校验。按实际调用核对 request、uploadFile、图片及下载链路和 WebSocket 域名，并以真机验收为准。
- 保留手填手机号、现有登录态存储命名空间和报名回跳流程。体验包版本递增至 1.0.1。

参考 [uni-app 微信小程序隐私协议开发指南](https://uniapp.dcloud.io/tutorial/mp-weixin-user-privacy.html)。

以下是核对清单。以当前后台选项、实际采集范围和运营方的真实处理方式填写，提交后在体验版检查指引正文能打开。

### 真机验收

- [ ] 未授权用户点击登录，原生弹窗可查看指引。拒绝后未调用登录接口，再次点击可重试。
- [ ] 同意后登录成功，新用户可补全昵称、头像，老用户登录态可恢复。
- [ ] 拒绝位置权限后可手动选城浏览。允许后定位、距离排序和地图选点正常。
- [ ] 无手机号用户报名时进入资料编辑，保存后回到原活动并可继续报名。
- [ ] iOS、Android 均检查隐私指引、相册及拍摄、图片加载与上传、聊天连接。

## 2. 分享配置

代码默认使用 `release`，生产容器实际值需在配置变更前复核。分享缓存键包含环境版本。体验版联调单独记录 `trial` 行为，正式发布使用 `release`。已有正式版本后分别核对小程序码、URL Link、扫码落地页面和错误日志。首发阶段先验收微信好友卡片。若接口返回 85079，结合实际发布状态和微信响应核对原因。

该变量仅影响 `/sharing/{kind}/{id}/{code|link}` 两个接口生成的小程序码和短链指向的环境，不改变小程序自身行为、体验版访问方式和审核通道。`check_path` 随 `release` 变为 `true`，未发布正式版时 `getwxacodeunlimit` 会因正式版缺少页面返回 41030，因此**首次提审前保持 `trial`，正式发布之后再改为 `release`**。URL Link 在无正式版本时恒返回 85079，与变量取值无关。

## 3. 支付和退款回调

将 443 作为拟验证入口。微信支付 APIv3 要求 `notify_url` 使用可公网访问的完整 HTTPS 路径且无查询参数。现有材料不能证明 8443 已被微信拦截，也不能据此推断商户平台必须额外填写一个通用回调域名。先核对当前商户产品配置和线上实际值。参考 [微信支付回调通知注意事项](https://pay.wechatpay.cn/doc/v3/merchant/4012075420)。

拟调整地址为 `https://www.tennisplaynow.site/api/v1/bookings/wx-notify`。仓库中支付和退款路径均引用 `WX_PAY_NOTIFY_URL`。配置生效后，使用获准的真实测试单分别核对支付、退款通知及业务状态。区分微信通知落账和主动查单落账。预检通过和接口可达仅作为配置检查。变更前记录旧值，回滚后复核回调和订单状态。

## 4. 部署依赖与提审顺序

1. 构建体验包并检查实际产物。默认启动页应为 `pages/home/index`，确认域名校验和位置声明。
2. 体验验收与后台隐私指引配置可以并行。2026-11-08 复核时，公网 `GET /api/v1/clubs/1/activities?phase=upcoming` 返回 404。本地俱乐部详情页依赖这条新路由，当前体验包中的活动 Tab 依赖后续后端部署。
3. 后端部署单独确认提交范围，排除既有落地页改动。按 CI/CD 流程以固定 SHA 部署，确认工作流、容器版本、迁移、健康检查和公网新接口，再测活动分页及赛事排名。按生产运维文档判断回滚条件。
4. 提审前确认后台指引状态、服务类目、合法域名、真机授权路径和资金链路均已验收。体验包上传与设置体验版、提交审核及正式发布分别记录。
   - 首发（无现网版本）走提审页入口：在「管理-版本管理-提交代码审核-信息填写页」（入口2）随版本一并提交隐私指引，且该页底部「用户隐私保护指引设置」必须选「采集用户隐私」——选「未采集」会在发布后回收全部隐私接口权限。
   - 入口1（账号设置-服务内容声明）那份审核中不阻塞提审；它针对现网版本，发布后生效覆盖。已核实社区案例：入口1卡审核中 7 天，走入口2提审后代码审核照常通过。
   - 指引未生效期间，真机调用定位/相册报 `api scope is not declared` 属预期，勿据此改代码；等入口1过审后再补测这几项。
5. 正式发布后完成分享链路验证。UGC 内容安全接口接入单列，提审时按实际能力说明处理机制。

本批保留 8443 监听和旧登录态命名空间。手机号继续手填，隐私正文由微信后台指引承载。
