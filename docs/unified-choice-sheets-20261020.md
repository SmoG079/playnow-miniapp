# 选择项弹窗统一（2026-10-20）

参考 GameConnect 的底部选择交互，使用现有 Wot UI 2.3.2 Popup 实现统一选择弹窗：标题、关闭按钮、选项说明、当前值回显，以及浅绿背景与绿色勾选标记。付款方式保留在报名费上方，以整行入口替代并排按钮；费用为 0 时仍提示免费参加。

共用组件为 `ChoiceSheet`、`ChoiceSelect`、`ChoicePicker` 和 `ChoiceMultiSelect`。普通单选点击即提交并关闭；真正的多选先修改临时值，点“确定”才提交，关闭或点击遮罩丢弃临时修改。原生枚举 picker 的适配组件保留原有数字索引事件，使筛选、加载和表单逻辑保持原有行为。

统一范围：

- 约球和比赛付款方式。
- 比赛创建的赛制、比赛项目、搭档方式、主办俱乐部和预订俱乐部；移除重复挂载的俱乐部弹窗。
- 比赛详情的报名分组、性别、更换参赛组、录入胜者和排场场地；支持在编辑弹窗上再打开选择弹窗。
- 首页排序、活动类型、NTRP 等级；个人资料等级、我的活动类型、申请类型；俱乐部工作台和经营统计中的俱乐部选择。
- 时段管理的场地及时间间隔；价格规则类型和生效星期多选。

日期、时间、地区沿用专用选择器。页面导航标签、签表组别导航、操作按钮、开关和已在问卷弹窗内的等级评估卡片保留各自交互。已有校验、报名和支付规则不因样式统一而改变。

弹窗使用 root-portal 处理父级弹窗和布局层级；在标签页打开时暂时隐藏原生自定义 tabBar，关闭或页面离开时恢复。个人资料的等级索引按半级字符串归一化，避免 3 与 3.0 导致选中回显错误。

## 验证

类型检查、219 项前端测试、Wot 用法检查及小程序生产构建通过；Wot 检查保留其数据集中已有的组合子组件警告，没有错误。

`frontend/tests/activity-payment-ui.cjs` 在本地 H5 完全拦截 API 请求，验证付款方式、费用确认、线下直接报名、选项回显、草稿恢复、项目切换时搭档选择重置、首页筛选索引、多选取消与确认，以及排场编辑内的嵌套选择。没有访问或修改线上业务数据。
