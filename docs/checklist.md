## 检查方法

1. 后端 API：检查 `backend/app/api/v1/` 各模块
2. 数据库模型：检查 `backend/app/models/models.py`
3. 前端页面：检查 `miniprogram/pages/` 各页面
4. 接口联调：检查 `miniprogram/utils/request.js` 和页面 JS 中的 API 调用
