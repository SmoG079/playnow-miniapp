# 订场自助取消与全额退款（2026-10-14）

按负责人最新规则启用自助退款，替代此前“真实已付款只能管理员退款”的保护入口，以及旧 24 小时全退/半退规范。范围为场地预约；本轮未调整比赛的报名截止及取消设置。

## 规则与状态

- 使用预约首个时段的 **Asia/Shanghai** 时间。距离开始 **超过 1 小时** 可自助取消；**恰好剩余 1 小时、1 小时内、开始后** 均拒绝取消。
- 已实际收款订单按服务端订单金额快照 **全额退款**，不接受客户端指定自助退款金额。后端由订单外键明细查询首个时段，不依赖客户端时间或客户端金额。
- 先持久化退款单、金额与 `refunding` 状态，再尝试调度后台任务；派发失败仍由已有周期任务兜底。申请受理不等于到账，退款最终确认后只释放本订单仍拥有的时段。
- 自助取消、管理员退款及后台恢复共用退款意图。重复取消、重复管理员全额退款与并发请求复用原单；已申请的部分退款不另建自助全额退款单。`refunding/refunded` 重试仅返回原结果，即使重试时已过截止时间也不新增退款。
- 待支付和 `dev_` 占位订单同样遵守一小时取消边界，允许取消时仅释放自己的时段、不伪造真实退款。已付款但没有真实交易凭据的历史订单拒绝自动退款，保留预约供管理员核对。
- 管理员退款仍是独立权限入口，不受用户自助取消窗口限制；历史多笔退款、异常和关闭状态需人工核对。

`GET /bookings/config` 固定返回 `free_cancel_hours=1`；即使部署环境遗留 `FREE_CANCEL_HOURS=24`，也不会覆盖新产品规则。配置字段默认值同步改为 1，保留字段兼容环境文件。

前端确认预约及我的预约页显示一小时规则；截止后的取消按钮禁用，点击处理函数也复核时间。上海时间带明确 `+08:00` 解析，避免设备时区改变判断。合法已付款取消弹窗明确申请全额原路退款，提交后显示“已申请全额退款”，不提前声称到账。
