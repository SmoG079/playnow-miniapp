交互检查记录：

- 从订场列表进入详情，再返回列表：新增列表请求 **0 次**。
- 详情首屏加切日期：俱乐部详情请求 **1 次**，时段请求 **2 次**；切日期没有重复请求俱乐部。
- 点击可订时段：显示连续时段选择及金额。
- 点击发布约球卡片：打开原约球表单。
- 约球详情加载失败后点击重试：恢复详情内容。

UI 内容与权限场景使用模拟器临时接口、存储 mock；未提交报名、支付、保存表单或生成排期。生产 API 配置未更改。mock 及模拟器内临时数据在检查后清理并刷新，未将样例接入产品源码。
