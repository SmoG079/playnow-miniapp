这是最容易误判的一步：**过户会重置 3 天等待期**，之前那次实名的等待时间不能复用。

腾讯云官方原文（备案限制说明，2026-09-17 更新）：

> 备案的域名要求为已通过实名认证的域名，且**认证完成时间满 3 个自然日**（非腾讯云注册的域名需要满 3 个工作日）可以提交备案订单，当域名实名通过工信部比对一致之后才会进入腾讯云审核。

官方 FAQ 进一步点明：

> 域名已实名认证的情况下，若您备案前需要**调整域名实名认证信息**，请在**域名实名认证通过后并且满 3 个自然日**（非腾讯云注册的域名需要满 3 个工作日）再进行备案。

**起算点是「新实名审核通过」那一刻，不是提交过户那一刻。**

| 时间锚点 | 含义 |
|---|---|
| ❌ 不是域名注册时间 | 2026-05-25 那次早已失效（信息已变更） |
| ❌ 不是提交过户的时间 | 审核还没结束 |
| ✅ 是**过户后新实名显示 `Approved`** 的时间 | 从这一刻起数 3 个自然日 |

**原因**：实名数据要上传到工信部入库，这个过程需要 3 个自然日。没入库就提交，管局核验时查不到新的实名信息，订单会被驳回。

**换算示例**（假设今天起动手）：

| 日期 | 动作 |
|---|---|
| 10-12 | 新建个体户信息模板（审核 1~3 工作日） |
| 10-15 | 用新模板提交「域名信息修改」，验证原持有者邮箱/手机 |
| 10-16 ~ 10-17 | 注册局审核通过 → 实名状态变 `Approved` ← **3 天从这里算** |
| 10-20 | 满 3 个自然日，可提交备案订单 |

> 3 天是**自然日**（含周末），不是工作日。

**赶时间的做法**：这 3 天不要空等，先把下面这些备齐并签署完，等实名一通过就立刻提交备案：

- **证件类**：个体户营业执照彩色照片、经营者身份证正反面（原件拍照，四角完整、无反光）

**机制**：工信部备案系统对主体有**唯一性**约束，判定依据不是单位名称，而是「**主办单位证件类型＋证件号码**」：

> 备案系统对主体的要求必须唯一性，即一个主体只能有一个备案号。判断主体冲突，并不是以主办单位名称为标准，而是依据「主办单位证件类型＋证件号码」来判断主体是否唯一的。如果提示主体冲突，就说明**该证件号码已经在备案库中存在了**。
> —— 工信部 / 广西管局《网站备案常见问题解答》

**因果链还原**：

| 步骤 | 状态 |
|---|---|
| ① 网站备案订单**创建时**（早于 10-13） | 该主体在工信部备案库中**不存在** → 订单类型登记为「**首次备案**」 |
| ② 10-13 小程序备案通过 | 主体「扬州市广陵区腾达体育活动中心（个体工商户）」凭统一社会信用代码**写入备案库，获得备案号** |
| ③ 10-14 网站订单提交管局 | 管局按「首次备案（新增主体）」受理校验 → **该证件号码已存在** → **网站主办者冲突** |

**关键结论**：订单的备案类型在**创建那一刻就被冻结**了，不会随主体状态变化自动改写。小程序备案先行通过后，这个订单的正确类型应是「**新增网站**」（原主体已有备案号，新增网站/APP）—— 类型没重算，就是本次驳回的根因。

**处置（腾讯云官方两步法）**：

| 控制台页面表现 | 含义 | 操作 |
|---|---|---|
| 有「**去修改并重新提交**」按钮 | 数据已同步完成，修改入口可用 | 直接点击 → 确认订单内容无误 → **提交审核** |
| 弹窗提示「**放弃备案**」 | 系统正在同步其他渠道的备案数据，修改入口暂不可用 | 点「放弃备案」→ **重新提交一次备案订单** |

腾讯云官方 FAQ（2026-09-11 更新）对第二步的措辞正好点明本场景：

> 建议您单击"放弃备案"后，重新提交一次备案订单，以便系统**完整校验您的信息、匹配正确的备案类型**，避免再次提交失败。

⚠️ **重新提交时最关键的一点**：务必确认系统给出的备案类型是「**新增网站**」。若仍以「首次备案」提交，会**二次驳回**。提交前用控制台的「验证备案类型」看清结果，跟着系统给的类型走，不要手动改回去。

**重新提交前的三项自检**：

1. **主体名称逐字一致**：必须与小程序备案登记的名称**完全相同**（含括号全角/半角、空格）。微信开放社区有常见驳回案例正是括号全角/半角差异导致 `(1003) 网站主办者冲突`。域名所有者现为 `扬州市广陵区腾达体育活动中心（个体工商户）`（**全角括号**），直接复制该字符串。
2. **证件号码用统一社会信用代码**：若两处填的号码不一致（如一处用营业执照注册号），同样会命中"网站主办者冲突"。主体是新建立，风险低，但值得核一眼。
3. **两条线不要同时送审**：一个主体同一时间只能有一个订单在管局审核（并存规则，本次未触发，但下次要避开）。

## 5. 主流程：腾讯云 ICP 备案

前置条件全部满足后，在 [ICP 备案控制台](https://console.cloud.tencent.com/beian) 提交：

| 步骤 | 内容 | 要点 |
|---|---|---|
| 1 | **验证备案类型** | 备案区域＝营业执照注册地；主办单位性质＝**企业**（个体户一律以企业备案）；云资源选 `lhins-ducollwg` |
| 2 | **填写主体信息** | 主办单位名称＝个体户全称（无字号写「xxx个体工商户」）；主体负责人＝**经营者本人** |
| 3 | **填写网站信息** | **应用服务类型选「网站/域名」**（不要选 APP / 小程序）；逐字段对照见 5.2 |
| 4 | **人脸核验 + 上传材料** | 用微信小程序「腾讯云备案」扫码做人脸核验；上传证件照片 |
| 5 | **腾讯云初审 → 短信核验 → 管局审核** | 初审 1~2 工作日；短信核验须在收到后 **24 小时内**完成；管局审核 20 个工作日内（通常 7~20 天） |

### 5.1 「应用服务类型」怎么选

腾讯云备案控制台在「互联网信息服务」环节会问「**应用服务类型**」，选 **`网站/域名`**。

| 为什么不选其他 | 说明 |
|---|---|
| 不选「小程序」 | 腾讯云这里的「小程序」指的是**小程序本体备案**，会把你引导回微信公众平台（就是你看到的那句提示）。你这条线的目标是让 `tennisplaynow.site` 恢复 80/443 访问、并能填进微信后台的「request 合法域名」，那属于**网站/域名备案** |
| 不选「APP」 | APP 备案需要填包名、公钥、签名 MD5，你没有原生 App，填不出来 |

腾讯云官方文档（新增/接入服务）对该字段的写法就是一句：**「应用服务类型 请选择网站/域名」**，随后填「域名」和「云资源」。

> 两条线的关系：**网站/域名备案（腾讯云）≠ 小程序备案（微信公众平台）**，互不替代，可并行，但**顺序上域名线要先行** —— 小程序备案需要填写后端接口地址（服务器域名），该域名必须已完成 ICP 备案。

### 5.2 「网站/域名」页逐字段对照

| 字段 | 填什么 |
|---|---|
| 应用服务类型 | **网站/域名** |
| 域名 | `tennisplaynow.site`。**一个网站只能填 1 个域名**，根域名和 `www` 属于不同网站，如需两者都备案要「新增网站/APP」再加一条（企业备案一单最多 10 个） |
| 服务名称（网站） | 用「**主体字号 + 业务**」，如「××网球服务平台」。**不要**填纯英文/纯品牌名（如 PlayNow）——命名规则要求与主体相关，纯英文品牌名是常见驳回项 |
| 服务内容（网站） | 选「**其他**」。你不属于综合门户/单位门户；且「其他」不会触发前置审批（游戏、新闻、出版、影视等才需要） |
| 服务语言（网站） | 中文简体 |
| 云资源 | `lhins-ducollwg`（上海，到期 2027-05-25）。系统通常会自动拉取 |
| 前置审批类型 | 以上都不涉及（**仅单位备案有此选项**，个人备案无） |
| 备注 | 如实说明：本域名仅用于微信小程序后端接口与静态资源。**不要**写"商城""在线支付""会员""分润"等经营性描述 |

> 企业备案在「新增」类型下，一个订单最多可提交 10 个网站；同一账号同一时间**只能有 1 个进行中的备案订单**。

**通过后**：
- 80/443 拦截自动解除
- 网站底部必须悬挂备案号并链接 `https://beian.miit.gov.cn`
- `static.tennisplaynow.site` 可以接 CDN 了

> ⚠️ 江苏管局特别提示："网站内容不能是涉及前置审批、论坛或**经营性**等内容"。
> 本域名仅作小程序后端接口与静态资源，落地页文案已按此定位撰写，备案时如实说明用途即可。
