# 活动分享（2026-10-15）

约球和比赛详情页底部提供无背景的“分享”图标，点击后显示微信好友、生成海报、二维码、复制链接四项。

- 微信好友使用原生 `open-type="share"`；可选择好友或群聊。普通分享不包含搭档邀请令牌。
- 海报由前端 Canvas 绘制活动标题、时间、地点、人数、费用和对应小程序码，可保存或通过微信图片分享面板分享。朋友圈页面分享仍由右上角菜单触发；图片分享由客户端能力决定。
- 二维码由服务端调用微信 `getwxacodeunlimit`，scene 为活动 ID，page 为对应详情页。两个详情页均处理微信扫码传入的 scene。
- 复制链接调用微信 `generate_urllink`，链接指向活动详情，30 天有效；不复制内部路由或后端接口。

`GET /api/v1/sharing/{post|tournament}/{id}/{code|link}` 仅为已存在且非草稿的活动生成资源。Redis 缓存一天，限制 IP 请求、单活动生成次数并加生成锁；微信异常返回失败，不缓存伪图片、错误 JSON 或伪链接。access_token 与手机号能力共用服务，仅保存在后端。

生成能力依赖正式小程序已发布对应页面、有效 AppID/Secret、微信接口权限和配额。生产探针需记录微信实际结果。小程序上传、审核及正式发布与后端发布分开验收；未发布的前端代码不代表微信正式版已更新。
