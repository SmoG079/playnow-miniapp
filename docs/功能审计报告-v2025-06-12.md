## 二、❌ 缺失功能清单

### 🔴 高优先级（影响运营）


| #   | 功能             | 说明                                                                                              | 影响              |
| --- | -------------- | ----------------------------------------------------------------------------------------------- | --------------- |
| 1   | **消息通知后端 API** | 缺少 `GET /notifications/{id}`, `PUT /notifications/{id}/read`, `GET /notifications/unread-count` | 消息系统无法正常工作      |
| 2   | **管理后台后端 API** | 缺少 admin 专用路由（数据统计、批量操作）                                                                        | 管理后台部分功能依赖现有API |
| 3   | **微信退款 API**   | 取消订单后未调用微信退款接口                                                                                  | 用户无法真正收到退款      |
| 4   | **场地签到/核销**    | 无扫码签到功能                                                                                         | 无法验证用户是否到场      |


### 🟡 中优先级（提升体验）


| #   | 功能              | 说明               | 建议         |
| --- | --------------- | ---------------- | ---------- |
| 5   | **场馆评价系统**      | 用户订场后无法评价        | 增加信任度      |
| 6   | **会员/积分系统**     | 无会员等级、积分、折扣      | 提升留存       |
| 7   | **优惠券系统**       | 无优惠券/ Promo Code | 营销工具       |
| 8   | **数据报表**        | 无收入统计、场地使用率图表    | 运营决策       |
| 9   | **消息推送 (微信订阅)** | 仅站内信，无微信服务通知     | 提醒效果差      |
| 10  | **客服系统**        | `chat/` 页面是占位符   | 需接入微信客服或IM |


### 🟢 低优先级（锦上添花）


| #   | 功能           | 说明                           |
| --- | ------------ | ---------------------------- |
| 11  | **多运动类型支持**  | 当前硬编码为网球，但模型支持多类型            |
| 12  | **赛事签位编排**   | `tournament-detail` 有占位符，未实现 |
| 13  | **赛事分组/淘汰赛** | 需复杂算法支持                      |
| 14  | **社交功能**     | 关注、粉丝、动态                     |
| 15  | **视频上传**     | 仅支持图片                        |
